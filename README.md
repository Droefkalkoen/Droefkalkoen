I build games, audio tools, websites and software for education.

## What I work on

- **Games in Unity (URP)** – I like simulations and machine learning and try 
  to focus on emergent gameplay with physics and ragdolls, crowd simulation with
  Burst/Jobs, enemies driven by ML-Agents, etc.
- **Audio** – I'm working on a Rack Extension for the Reason DAW 
  (Lua configuration + C++  DSP) and the tooling around it. 
- **Education** – code examples, GitHub integrations 
- **Websites** – fast static sites with Astro.
- **Home** – Home Assistant automations and small Python tools for things
  like scraping, data and tracking workouts.
